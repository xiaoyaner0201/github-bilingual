# Privacy Policy — GitHub Bilingual

GitHub Bilingual (browser extension and userscript) does not collect, transmit, sell or share any user data.

- It makes no network requests of its own.
- It runs only on `https://github.com/*` and only reads the text of rendered issue, pull request and comment bodies on the page you are viewing, to decide which language to show. That text never leaves your browser.
- The only stored value is your language preference (`auto`, `zh` or `en`), saved with the browser's `storage` API (synced by your browser if you have sync enabled).
- No analytics, tracking or third-party code.

Contact: https://github.com/xiaoyaner0201/github-bilingual/issues

# 隐私政策

GitHub Bilingual（浏览器插件与油猴脚本）不收集、不上传、不出售、不分享任何用户数据。只在 github.com 上运行，只在本地读取当前页面正文以决定显示哪种语言；唯一保存的是你的语言偏好（auto / zh / en），存于浏览器 storage。没有统计、追踪或第三方代码。
